# QEC 论文信息抽取清单

在完成输出前，逐项核对：

## 1. 基本信息

- 是否写明论文标题。
- 是否先写了 `## 0. 摘要概述`。
- 摘要概述是否覆盖：问题、方法、主要结果、意义。
- 是否写明目标码族或任务。
- 是否判断了论文类型：算法、硬件、协同设计、噪声建模。

## 2. 算法信息

- 是否明确写出解码器/模型名称。
- `Weight Type` 是否遵循固定规则：原文明确说支持 weighted edges 写 `Arbitrary`，否则写 `N/M`。
- 是否记录 LER、阈值或等价逻辑错误性能。
- 是否给出 LER 对应条件：`d`、`p`、轮数、噪声模型。
- 是否提取理论复杂度或经验扩展趋势。
- 是否说明与哪些基线做了比较。
- 是否总结至少 2 条核心优势。

## 3. 硬件信息

- 是否写明实现平台：FPGA、ASIC、CPU、GPU、TPU。
- FPGA 是否记录器件型号、LUT/FF/BRAM/DSP 等资源。
- ASIC 是否记录工艺节点、面积、SRAM、功耗、频率。
- 是否记录温度，例如 room temperature、4 K、mK；若无是否写 `N/M`。
- 是否记录所用噪声模型；若文中没有明确说明，是否写 `N/M`。
- 是否记录延迟、吞吐、每轮解码时间。
- 是否标注数据来源：综合、后仿、板级测试、芯片实测。

## 4. 噪声模型

- 是否写明噪声模型名称。
- 是否说明覆盖哪些错误源：测量、重置、单/双比特门、泄漏、擦除。
- 是否说明是否包含时空相关或 hook error。
- 是否记录参数范围与实验设置。

## 5. 写作质量

- 是否把数字与条件绑定，而不是孤立罗列。
- 对缺失项是否明确写 `N/M`。
- 是否同时写了优势与局限，而不是只写优点。
- 文件末尾是否包含固定字段的“论文指标表”：

| Implementation | Algorithm | Distance | Weight Type | Memory | LER | Decode time | Frequency | Power | Temperature | Noise Model |
