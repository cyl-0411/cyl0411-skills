# Output Style

Use this reference only when the user asks for a consistent report shape or many commands at once.

## Single Command

```text
`commandName`

作用：...
基本语法：...
关键参数：
- `-option`: ...
常用写法：
```tcl
...
```
使用阶段：...
注意事项：...
相关命令：...
```

## Multiple Commands

Group commands by flow stage when the user provides a mixed list. Keep each command compact and add a final "建议顺序" Tcl snippet if the commands form a runnable flow.
